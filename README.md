Эта страница была создана для лёгкого и удобного крафта элементов в задании по предмету Химия на осеннем ивенте «Цниверситет - 2026» на проекте GTA5RP. Был использован файл «720 синтезов-1.txt», который был выложен в дискорд-канале Гайдеса Q-D. Есть две вкладки: первая предназначена для построения рецепта для одного элемента, вторая - для построения единого дерева крафта для десяти элементов. Во второй вкладке можно ввести любое количество элементов до десяти.
